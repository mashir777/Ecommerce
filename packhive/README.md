# PackHive

Food packaging ecommerce storefront inspired by packagingbox.pk — built with Next.js + Tailwind.

## Setup

```bash
cd packhive
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — run production server

## Pages

- `/` — Home (hero, categories, products)
- `/shop` — Product catalog with category filters
- `/product/[slug]` — Product detail + WhatsApp order
- `/quote` — Free quote form
- `/contact` — Contact form
- `/about` — About PackHive

## Brand notes

Brand name is **PackHive** (slight change from PackagingBox). Contact details in `src/lib/data.ts` can be updated for your business.
